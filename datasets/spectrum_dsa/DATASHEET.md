# Datasheet — Federated DSA Decision-Trace Dataset (`spectrum_dsa`)

**Version:** 1.0.0 · **License:** Apache-2.0 · **Format:** JSONL (one decision per line)

## Motivation
A reproducible benchmark of **federated dynamic-spectrum-access (DSA) decisions
passed through the Horizon-RIC trust layer**, under honest and adversarial
(poisoning) conditions. It exists so reviewers can evaluate, without running any
training, whether the Decision Safety Shield keeps emissions legal and the audit
chain intact even when the upstream federated DSA policy is poisoned. It is the
data counterpart to `benchmarks/secure_dsa_benchmark.py`.

## Composition
- **1,620 rows** spanning multiple **attacks** (`none`, `qtable_target`, `alie`,
  `fang_krum`, `fang_median`) × **aggregators** (`fedavg`, `median`, `krum`,
  `trimmed_mean`) × rounds. Each row is one shielded DSA decision.
- Each record contains the *proposed* (channel, power) from the federated DSA
  agent, the Shield's *safe* action, the `SafetyCertificate` summary, the
  violated invariants (if any), and the hash-chained evidence-record hash.
- A `label` marks honest vs poisoned provenance. See `manifest.json` for the
  exact attack/aggregator grid and row count.

### Schema (per line)
`trace_id, round, attack, aggregator, decision_id, obs_state,
proposed_channel, proposed_tx_power_dBm, emit, safe_frequency_hz,
safe_bandwidth_hz, safe_tx_power_dBm, safe_eirp_dBm, shield_safe,
shield_emit_blocked, shield_projected, shield_fallback_used,
violated_invariants, chain_hash, label`

## Collection / provenance
**Fully synthetic and deterministic.** Generated by
`datasets/spectrum_dsa/generate.py` from the `horizon_ric.spectrum` federated-DSA
environment + the real Shield + the real hash-chained evidence store, under fixed
seeds. No human subjects, no real RF captures, no PII. Re-running the generator
reproduces the committed files. ALIE follows Baruch et al. (NeurIPS 2019); Fang
attacks follow Fang et al. (USENIX Security 2020).

## Intended uses
- Evaluate trust-layer behaviour (legality + auditability) under poisoning,
  decoupled from any specific training run.
- A reproducible artifact for the AI-RAN Alliance Call "Datasets" output.

## Limitations (read before use)
- **Synthetic, not over-the-air.** The DSA environment and the carrier model are
  simplified; numbers are illustrative, not measured on srsRAN/Colosseum/Aerial.
- **Not a robustness claim.** Poisoned rows show the federated *policy* degrading;
  the dataset demonstrates the Shield's legality/audit guarantee holds regardless,
  NOT that the aggregators defeat adaptive attacks (they do not — see the README
  "honest status" section).
- Invariant thresholds (band, EIRP, PFD) are placeholders to be calibrated per
  deployment (M1–2).

## Regeneration
```bash
python datasets/spectrum_dsa/generate.py   # rewrites traces.jsonl + manifest.json
```
