# Datasheet — DeepMIMO ASU Campus 3.5 GHz evaluation slice

**Source:** DeepMIMO v4.0.0, scenario `asu_campus_3p5`  
**Purpose:** External-data evaluation of DSA channel selection and Shield legality

## What this is

The build script downloads the published DeepMIMO ASU Campus scenario and uses
the pinned DeepMIMO package to generate SISO OFDM channels. It deterministically
selects 4,096 receivers with valid propagation paths and reduces 60 OFDM samples
across 100 MHz into six subband-gain features.

This is site-specific **Wireless InSite ray tracing**, not synthetic random
numbers generated by Horizon-RIC. It is also **not an over-the-air measurement,
operator trace, real-radio test, or live O-RAN deployment**.

## Provenance and redistribution

`manifest.json` pins the DeepMIMO package release, release commit, downloaded
archive SHA-256, extracted scenario tree SHA-256, transformation, row count, and
derived feature SHA-256. The hash of a dataset tree includes every file's bytes,
not only names and sizes.

The downloaded scenario did not contain a separate dataset license file.
Consequently this repository does not redistribute the raw archive or row-level
derived features. CI downloads and regenerates them from the provider. Only
aggregate benchmark results and provenance hashes are committed.

## Reproduction

```bash
python -m pip install '.[realdata]'
python datasets/deepmimo_asu_3p5/build.py
python benchmarks/deepmimo_dsa_benchmark.py
```

DeepMIMO v4 requires Python 3.11 or later. Internet access is needed only for
the initial scenario download.

## Intended and prohibited interpretations

The output can test deterministic channel-selection logic and whether explicitly
configured Shield constraints are respected on published ray-traced channels.
It cannot establish RF conformance, field performance, carrier scalability,
vendor interoperability, or regulatory certification.
